# Планировка квартиры №33

Редактор расстановки мебели по плану БТИ. Работает в браузере, удобен на телефоне.
Всё в одном файле `index.html`, без сборки и без сервера.

## Как выложить на GitHub Pages

1. На github.com нажми **New repository**, задай имя (например, `planirovka`) и выбери **Public**.
2. В новом репозитории нажми **Add file → Upload files**, перетащи `index.html` и нажми **Commit changes**.
3. Открой **Settings → Pages**. В разделе *Build and deployment* выбери **Deploy from a branch**, ветку `main` и папку `/ (root)`, затем нажми **Save**.
4. Через 1–2 минуты сайт откроется по адресу `https://<твой-логин>.github.io/planirovka/`.

На телефоне можно добавить страницу на главный экран («Поделиться → На экран „Домой“» в Safari или «Добавить на главный экран» в Chrome). Тогда она откроется как приложение.

## Где хранится план

План хранится в памяти браузера на том устройстве, где ты его рисуешь. Чтобы перенести его на другое устройство или сделать резервную копию:

- **☰ → Скачать план (.json)** сохраняет файл со всеми вариантами;
- **☰ → Загрузить план из файла** добавляет варианты из файла к текущим, ничего не стирая.

Если очистить данные сайта в браузере, план пропадёт, поэтому время от времени скачивай файл.
